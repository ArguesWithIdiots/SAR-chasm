# Security Policy

## Supported scope

This project is an early demonstration and is not supported for production or confidential data.

## Reporting a vulnerability

Open a GitHub issue only when the report contains no secrets, API keys, personal information, SAR information, or confidential case material. For a sensitive security report, contact the repository owner privately through the contact method listed on their GitHub profile.

## If an API key is exposed

Revoke it immediately in the OpenAI Platform dashboard, create a replacement, and review project usage. Removing a key from the latest Git commit is not sufficient if the key appeared in repository history.
