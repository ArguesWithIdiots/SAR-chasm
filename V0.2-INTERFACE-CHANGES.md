# v0.2 Interface Changes

## Included

1. **Dark mode toggle**
   - Place it somewhere obvious near the top of the interface.
   - Apply dark mode consistently across the page background, panels, form controls, notices, scorecards, status indicators, and buttons.
   - Preserve readable contrast and clear pass/flag colors.
   - Remember the user's selection between visits when browser storage is available.
   - Respect the operating system color preference until the user makes an explicit selection.

2. **Scorecard overview**
   - Show a compact passed/flagged category count beside the overall result.
   - Preserve the five-category rubric order.

3. **Copy review**
   - Provide one button that copies the summary and all category results as clean plain text.
   - Do not persist narrative or review content.
   - Give clear success and failure feedback.

4. **Clear post-review action**
   - Add an obvious “Review another narrative” action after a scorecard is returned.
   - Clear the prior narrative and scorecard, reset confirmation, and return focus to the narrative input.

5. **Disabled-button guidance**
   - Explain whether Analyze is unavailable because the narrative is too short or because fabricated-data confirmation is missing.
   - Keep the message concise and update it as the form changes.

6. **Keyboard shortcut**
   - Allow `Ctrl+Enter` and `Cmd+Enter` to submit when the form is valid.
   - Make the shortcut discoverable near the Analyze button.

7. **20,000-character submission boundary**
   - Allow users to paste and edit narratives longer than 20,000 characters instead of truncating or rejecting the paste at the textarea.
   - Show the full character count and the exact number of characters over the limit.
   - Disable submission while the narrative exceeds 20,000 characters; retain backend enforcement of the same limit.

## Release constraints

- Keep narrative text out of browser storage; only the user's explicit theme preference may be persisted.
- Avoid numeric quality scores, charts, and decorative dashboard elements that imply false precision.
